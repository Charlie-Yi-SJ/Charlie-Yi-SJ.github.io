SFT-TA

Supervised Fine-Tuned Agents in Multi-Agent LLMs for Automated Inductive Thematic Analysis

SFT-TA introduces supervised fine-tuning of role-specialized agents for inductive thematic analysis, enabling disease-specific coding behavior and achieving near-expert alignment.

Key Contributions

  • First to incorporate supervised fine-tuning of role-specialized agents for inductive thematic analysis
  • Enabled disease-specific coding behavior
  • Achieved near-expert alignment with human qualitative annotations
