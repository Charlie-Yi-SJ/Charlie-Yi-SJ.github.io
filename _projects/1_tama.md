**TAMA** (Thematic Analysis with Multi-Agent LLMs) is a human-AI collaborative framework for automating inductive thematic analysis of clinical interview transcripts.

## Key Contributions

- **First** multi-agent LLM framework that mirrors the workflow of human qualitative researchers
- Assigns specialized roles (coder, reviewer) to automate thematic analysis of clinical interviews
- Achieved near-expert alignment with human qualitative annotations
- Reduced analysis time by over **99%**, transforming multi-day manual coding into an automated workflow
