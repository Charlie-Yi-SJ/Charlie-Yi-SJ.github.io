**Auto-TA** extends the TAMA framework with Reinforcement Learning from Human Feedback (RLHF) pipelines for policy-guided theme discovery and interpretability.

## Key Contributions

- Extended multi-agent framework with **RLHF** pipelines
- Policy-guided theme discovery for improved interpretability
- Developed a four-dataset cross-condition benchmark for large-scale validation
- Scalable approach for automated thematic analysis
